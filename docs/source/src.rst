API Reference
=============

The FLUGS API is organised into three subpackages:

- :doc:`api_core` — pipeline orchestration, configuration, data preparation,
  footprint interface, and the kernel-ridge inversion solver.
- :doc:`api_utils` — array/IO/logging helpers, configuration loader,
  data classes, diagnostics, environmental response functions, and the
  synthetic-data generator.
- :doc:`api_plotting` — style and label managers, time-series, response, and
  spatial plotters.
